# Item Mall Wishlist

Wishlist for the item mall.

Adds a wishlist to the item mall: wish for items and find them again in their own Wishlist list. Also stops the item cards shifting when the scrollbar appears.

An add-on for [ROSE Mod Launcher](https://github.com/Zurnny/Rose_Mod_Launcher), for the game's **default** UI. The [Steampunk UI](https://github.com/Zurnny/SteamPunk) theme already includes this, so you don't need it with Steampunk (if both are on, Steampunk's files win).

## Install
1. Download this repo (Code > Download ZIP) and open it.
2. Copy the **Item Mall Wishlist** folder into `Launcher Mods` in your ROSE Online folder.
3. Open the launcher, press **Mods**, tick **Item Mall Wishlist**, and restart the game.

It updates itself from this repo whenever the launcher opens.

## Files it changes
- `Data/ui/themes/rose/game/item_mall.css`
- `Data/ui/themes/rose/game/item_mall.html`

Turning it off in the launcher puts the game's own files back.
